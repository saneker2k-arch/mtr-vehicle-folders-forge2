# MTR Vehicle Folders (аддон для MTR 4.0.5: Fabric 1.19.4 и Forge 1.20.1)

Заменяет меню выбора поезда в депо (Siding) на меню с папками:
- **MTR** (зелёная): все вагоны, которые идут вместе с самим MTR.
- **Вид транспорта** (жёлтые): тег `family:` = train, bus, tram, monorail, trolleybus, subway, electricbus, car.
- **Прочее** (оранжевая): всё остальное (нет подходящего тега).

Внутри каждой из этих папок: **страна** (`iso_3166`) > **тип вагона** по id:
Головной (`_cab_1`), Промежуточный (`_trailer`), Хвостовой (`_cab_2`), Двухкабинный (`_cab_3`), Другие вагоны (без таких окончаний).
Если в стране нет ни одного вагона с распознаваемым окончанием, вагоны показываются сразу в папке страны.

Слева дерево папок и поиск, по центру описание вагона под курсором (название, длина, описание, теги),
справа выбранные вагоны. Логика выбора, «Дублировать», серые недоступные вагоны и отправка на сервер
остались от оригинального экрана MTR (наш экран наследует `VehicleSelectorScreen`).

## Папки в меню станций, маршрутов и депо

В меню MTR (вкладки «Станции», «Маршруты», «Депо») можно создавать свои папки, в том числе вложенные.
- Кнопка **«Папка»** справа от кнопки добавления: создать папку внутри открытой (название и цвет).
- Клик по папке открывает её, клик по строке **`..`** поднимает на уровень выше.
- Кнопки «изменить» и «удалить» на строке папки: переименовать/перекрасить и удалить (вместе с вложенными, станции при этом не удаляются, а возвращаются наверх).
- **Правый клик** по станции, маршруту, депо или папке: переместить в другую папку.
- Пока в поиске есть текст, показываются все элементы без учёта папок.
- Папки хранятся только у вас на компьютере: `config/mtrvehiclefolders/dashboard_folders.json`, отдельно для каждого мира или сервера. Другие игроки их не видят.

## Две версии

- **Fabric 1.19.4**: проект в корне (папка `src`).
- **Forge 1.20.1**: отдельный проект в папке `forge/`. Весь общий код берётся из `src`, у Forge свои только два файла,
  зависящие от загрузчика: `platform/Platform.java` и `mixin/MinecraftClientMixin.java`.
  Для сборки нужен MTR 4.0.5 для Forge 1.20.1 в `forge/libs/` под именем `mtr-forge-1.20.1.jar`, команда: `cd forge && ./gradlew build`.

На GitHub Actions собираются обе версии (два задания в `.github/workflows/build.yml`), готовые jar лежат в Artifacts.

## Сборка (Fabric)

1. Скачайте MTR **4.0.5 для Fabric 1.19.4** и положите jar в `libs/` под именем
   `MTR-fabric-4.0.5+1.19.4.jar` (или поменяйте `mtr_jar` в `gradle.properties`).
2. `./gradlew build` (нужна Java 17). Готовый мод: `build/libs/`.
3. Проверка в игре: `./gradlew runClient`.

Мод клиентский, на сервер ставить не нужно. Нужен MTR 4.0.5.

## Сборка в облаке (GitHub Actions)

1. Создайте репозиторий на GitHub и загрузите в него содержимое проекта (вместе с папкой `.github`).
2. Вкладка **Actions** > Build > Run workflow (или просто сделайте push).
3. Когда сборка закончится, откройте её и скачайте архив **mtr-vehicle-folders** из раздела Artifacts: внутри jar.

Jar MTR workflow скачивает с Modrinth сам. Если не получилось, положите его в `libs/` вручную и закоммитьте.

## Как это работает

- `MinecraftClientMixin` перехватывает `setScreen`: если MTR открывает `VehicleSelectorScreen`, подставляется
  `TaggedVehicleSelectorScreen`. При любой ошибке открывается оригинальное меню.
- `VehicleTree` строит дерево из `CustomResourceLoader.getVehicleTags(...)`.
- Вид транспорта берётся из тега `family`, страна из `iso_3166`. Самолёты и корабли имеют свои депо, поэтому у них отдельные меню.
- Папка открывается кликом по строке, «Назад» поднимает на уровень выше (или очищает поиск).
  Пока в поиске есть текст, показывается плоский список всех вагонов.
